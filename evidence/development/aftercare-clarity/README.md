# 가입 후 결과 화면 검증

새 모델 실행이 아닌 기존 실제 합성 응답의 UI 회귀 검증이다. `ui-fixture.json`은 이전 점검의 금리 비교·공식 조회에 화면 시험용 7개 답변을 조합했다. 실제 계정·운영 DB를 변경하지 않는다.

기본 715건 통과·선택적 96건 생략, 타입·빌드·lint 오류 0이다. 브라우저에서 단일 연 금리 3%→8.2%, 5.2%p 차이와 입력한 계약 1건, 미입력 6건 접기, 설명 보완 3건, 요청 문구 복사 완료 안내를 확인했다. Clipboard 직접 읽기는 브라우저 권한이 거부해 성공으로 표시하지 않는다. 복사 거절 주입 시 직접 선택·복사 안내가 나왔다. 요청 문구는 편집 가능하고 자동 발송하지 않는다.

정상·미입력·실패·부분 실패·긴급 결과 5종과 복사 거절을 확인했다. 긴급 결과는 기존 행동 안내가 차이 요약보다 먼저 나온다. 초기 Fixture route 갱신 시험은 이전 응답이 남아 실패했으며 기존 route를 해제하고 각 응답을 새로 연결한 뒤 재검증했다. 390px 가로 넘침 0, 미입력 details는 기본 접힘이다. 증거는 화면·레이아웃·변형 결과를 따른다.

표현을 개선했으며 실제 적용 금리·총이자·위법 여부를 새로 판단하지 않는다. 저장된 점검·Passport·모델·Migration·예산은 변경하지 않았다. 정식 OCR·Workflow·Release Gate 증거가 아니다.
