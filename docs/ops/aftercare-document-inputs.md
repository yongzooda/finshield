# 가입 후 계약 문서 입력

PC-008·PC-011을 기능 Draft에 연결했다. 계약 Image/PDF는 같은 Case에서 TUS·MIME/Magic Byte·격리 파서·OCR 별도 동의·PII를 거친다. 확인 전 인식 문구와 페이지를 보여 주고 사용자가 이전 Claim에 연결해 수정·확인한다. 확인 시 원본 삭제를 시작하고 마스킹 문구와 실제 출처 위치만 점검에 사용한다. 기기 내 원본 별도 보관을 업로드 전에 안내한다.

거래 전 Claim/Revision과 Passport는 유지하고 가입 후 문구는 전용 표에 남긴다. 재조회는 저장된 항목을 읽으며 OCR·모델을 다시 부르지 않는다. 같은 문구 확인의 응답 유실은 재시도로 복원한다. 이후 다른 문구를 확정하려는 요청, 타인 문서, 문서 출처 위조와 Worker 직접 본문 접근을 거부한다. 사용자 수정을 공식 Evidence로 취급하지 않는다.

격리 SQL 43 Migration·32시험 파일에서 소유권·목적 불변·동의 거부·확인/삭제 원자성·중복·출처 고정·기존 Claim/Passport 불변을 확인했다. API 시험은 확인 전 PII 처리·정리 실패의 미완료 표시·다른 Case 거부·상태 복원을 포함한다. 실제 Provider·Storage 표본과 브라우저 결과는 별도 후속 기록을 따른다. 원격에는 작성 시점 0042까지 적용됐다. 전체 OCR 품질·가입 후 판단 품질·장애 20종·Gate 재채택은 완료하지 않았다.
