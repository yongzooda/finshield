2026-09-08, 기준 main `8f9b40ad5c8f577280f66d626888b3ddba75bed0`.

## 문제와 수정 범위

사용자 PDF 결과에서 인용 오류 문장이 네 번 반복되고 Agent·적합성 내부 코드가 그대로 노출됐다. 선입금·원격제어 앱 설치 요구에도 ‘사실과 다름’이라는 라벨이 붙어, 요구를 받은 사실 자체를 부정하는 것으로 읽혔다.

RES-001·RES-008에 따라 새 검증 결과, Case 기록, Passport에 같은 표시 규칙을 적용한다. 위험 행동 요구와 공식 예방 지침 비교를 구분하고, 일반 상품 조건은 공식 자료와의 일치 여부로 표시한다. UNKNOWN·NEED_MORE_INFORMATION·WITHHELD를 확정 결과로 승격하지 않는다. 진위 축은 ‘상품·기관 정보 / 불일치 항목 있음’, 적합성 미평가는 ‘적합성 판단 보류’로 표시한다.

인용 검토 실패 원인은 중복 없이 설명하고 영향을 받은 검토 범위는 상세를 열지 않아도 보인다. 적합성 제한 코드는 한국어 목록으로 바꾼다. 원본 Run·Claim 판정·요약·Passport 해시와 DB·Provider·비용 정책은 변경하지 않는다. PASS-002의 기존 버전 불변 조건을 유지한다.

## 남은 품질과 배포

이번 브라우저 검증은 기존 합성 실행 데이터와 사용자 화면 조건을 조합한 UI Fixture다. 새 PDF 인식·실제 모델·DB 저장·Live E2E 측정이 아니며 추가 Provider 비용은 없다. 인용 검증 실패가 발생한 실제 실행은 여전히 PARTIAL이다. 같은 문서의 여러 Evidence 연결도 독립 출처 수 증가로 보지 않는다.

아직 운영 배포 전이다. 원격 필수 검사와 Preview를 확인한 뒤 병합해야 한다. 기존 GitHub Actions 결제/사용 한도 시작 실패가 계속되면 검사 우회 없이 Draft로 남긴다. Implementation NO-GO·Release NOT-EVALUATED를 유지하며 Gate 증거로 채택하지 않는다.
