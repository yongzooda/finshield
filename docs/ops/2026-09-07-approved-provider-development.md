사용자가 Cohere 학습 사용 끄기와 Fast 합성 개발 시험 최대 USD 0.05를 승인했다. 전체 P0 구현을 우선하고 품질·출시 Gate는 실제 검증과 구분하라는 지시도 확인했다.

Cohere 대시보드 Data Controls에서 이전 On 상태를 확인한 뒤 학습 사용 스위치를 Off로 변경했다. 별도로 새로 연 같은 설정 페이지에서도 Off·unchecked를 확인했다. 이전 On 관측 기록은 보존한다. 현재 로그인한 계정의 설정 확인이며 배포 Key와 계정 연결, DPA·ZDR·region·하위처리자 전체 확인을 대신하지 않는다.

승인 범위는 rerank-v4.0-fast 합성 20 Claim 개발 시험, 최대 25 search units·USD 0.05다. 기존 일일 잔여 예산 안에서 수행하며 자동으로 상한을 올리지 않는다. 실제 사용자 개인정보나 유료 계약·플랜 변경은 포함하지 않는다. 현재 이 승인으로 실행한 Provider 호출과 비용은 0건·USD 0이다.

기존 평가셋 실패와 기준은 유지한다. 개발 결과를 정식 Gate PASS로 채택하지 않으며, 실제 계정 설정과 검색 품질은 별도로 검증한다.
