# Red Team 반박 인용 범위와 금융 문구 오탐

AI-012·SEC-PRI-010, 이슈 #294·#300. 실제 PNG 6 Claim 시험은 58.524초에 저장됐지만 Red Team의 CITATION_INVALID 때문에 PARTIAL이었다. 원본은 `evidence/development/ocr-recovery/png-first-live.json`에 보존한다. 정확한 실패 출력 원문은 보관하지 않아 그 한 번의 잘못된 ref를 소급 확정하지 않는다.

Red Team의 단일 Claim 판단 입력을 기존 Citation Validator에서 CONTRADICTED에 사용할 수 있는 자료로 제한했다. 자격 있는 반박 자료가 없으면 실제 독립 검색 결과의 범위에서 NONE_FOUND를 기록한다. 모델에게 빈 자격 목록으로 확정 인용을 선택하게 하지 않는다. 자료가 있으면 실제 모델이 원문을 판단하며 근거의 자격이 곧 실제 반박을 의미하지 않는다. 원래 ref 복원과 사후 Citation Validator는 유지한다. 이전 실패 결과를 성공으로 고치지 않는다. 새 Agent v12·Manifest v20은 0068로 추가하고 과거 정의를 보존한다.

같은 PNG에서 PII 마스킹이 “입금하고”의 일부를 뒤 문장 상담원 앞의 이름으로, “안내하는”과 “권유문입니다”를 맨이름으로 가렸다. 직책 앞 이름은 어절 시작에서만 잡고, 성씨만으로 추측하는 마지막 규칙에서 금융 서술어·문서 명사를 구분했다. 명시된 성명·호칭·직책에는 이 추가 예외를 적용하지 않는다. 같은 글자를 실제 이름으로 라벨링한 시험도 가려짐을 확인했다.
