# 회원 권유 검증의 근거 사용 범위 수정

요구사항 CLM-001·AI-009·AI-010·EV-004·EV-007·EV-009·RES-004의 결함 수정이다. 사용자 제공 합성 PDF의 SHA는 `3b4edb0a7075f273ddfa1c426bb818bd4df2ae1c48011f8e191d17830cc53a1a`다. 이미 결과를 본 재현 표본이므로 정식 Claim 품질 평가셋으로 채택하지 않는다.

## Live 재실행 전 확인 기준

- 현재 가입 가능하다는 햇살론15 권유는 공식 보증 종료 고지와 비교해야 한다. 종료 전 조건을 현재 판매 조건으로 승격하지 않는다.
- 금리와 한도는 별도 Claim으로 추출하고 원문의 단위·상품 문맥을 보존한다.
- 사용자 확정 문구의 요구 조건이 공식 안내와 맞는지 검증한다. 실제 대화의 발생이나 상대의 범죄 사실을 입증하는 문제로 바꾸지 않는다.
- 선입금·원격제어 요청의 위험과 필요한 행동을 구체적으로 설명한다. 개인 승인 여부와 실제 발신자 신원은 자료가 없으면 보류한다.
- CoVe도 소비자 안내를 독립 조회할 수 있어야 한다. 초기 Agent 결과·검색을 재사용하지 않는다.
- 유사 사건·범죄 사실은 일반 안내만으로 확정하지 않는다. 종료 고지는 현재 가입 가능성을 뒷받침하는 인용에 사용할 수 없다.
- 부정문(선입금하지 말라, 원격제어 앱 설치를 거절하라)과 정상 공식 앱 신청을 위험 요구로 뒤집지 않는다. 실패·만료·본문 변경은 성공으로 숨기지 않는다.
- 같은 PDF의 업로드·선택·검증·저장·재조회·삭제를 실제로 확인한다. 전체 Release 또는 B-CLAIM-01 성공으로 표시하지 않는다.

## 출처 해석

현재 상품 페이지의 종료 안내는 '종료 사실'에 대한 직접 근거다. 해당 페이지의 종료 전 금리·한도는 현재 가입 가능성을 지지하지 않는 맥락 자료로 유지한다.

서민금융진흥원 공지 24020의 2021-05-27 예방 지침은 작성일을 보존한다. 일반 예방 지침의 공식 게시 내용과 현재 권유의 발생·사기 확정은 다른 명제다. 검토한 본문 Hash와 검토 기한을 명시하고, 기한 안에 같은 공식 본문을 다시 가져온 경우에만 안내 내용과 요구 조건의 비교에 사용한다. 본문 변경·검토 기한 만료 시 기존 참고 자료 상태로 돌아간다. 최신 사건 경보 또는 현재 거래의 위법 증거로 표현하지 않는다.

## 복수 항목 재현 실패와 추가 변경

첫 후보는 PDF 검증 90.469초, 분할 후보는 86.085초에 저장됐지만 독립 검토가 실패해 부분 결과였다. 두 원본을 `evidence/development/member-evidence-scope/`에 보존했다. 첫 원장의 공식 페이지 조회는 263~336ms였으며 모델 판단 8초 상한이 CoVe를 중단했다.

세 번째 후보는 판단을 3개 항목씩 나누고, 호출 내부 인용 번호만 연속 번호로 바꾼 후 출력에서 원래 번호를 복원한다. 제공된 근거만 허용하는 Schema와 사후 인용·독립성 검사는 유지한다. 실행 전역 번호 차이로 출력 Schema가 매번 달라지는 비용을 줄이기 위한 변경이며, 지연 감소는 Live로 별도 확인한다. [Anthropic 공식 설명](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)에 따르면 새 Schema는 grammar 준비 지연이 발생한다.

Migration 0055의 v9은 기존 v8을 보존한다. Domain 단계 16초, 독립 검토 단계 18초, Judge 12초로 단계 상한 합 112초이며 저장 여유 6초까지 Text 120초 안이다. 호출 시간 상한·전체 Run 취소·비용 예약은 계속 적용한다. 개인 승인과 정상 안내의 부정 표현을 별도 합성 표본으로 함께 점검한다.

세 번째 후보도 92.296초에 부분 저장됐다. CoVe는 정상 종결됐지만 다른 단계 및 Judge의 개별 상한으로 보류됐다. 본문 분할·인용 정규화가 전체 품질 성공이라는 뜻은 아니다. 실패 원본을 보존한다.

네 번째 후보(v10, Migration 0056)는 개별 단계 최대 대기를 Domain/검토 각각 25초, Judge 20초로 두고 기존 전체 Run의 AbortSignal을 그대로 합성한다. 최대 대기를 모두 순차 예약하는 방식이 아니며, 전체 120초(Text)/180초(파일) 기한을 늘리지 않는다. 기존 v9의 112초 합산 설정은 과거 시도로 보존한다. 다음 검증은 같은 PDF 외에 정상 안내 Text를 반드시 포함한다.

공유 실행 기한은 115초에서 저장 여유 6초를 뺀 109초다. Domain·검토에는 마지막 Judge의 최소 10초를 남긴 신호를 주고, Judge는 남은 시간 안에서 최대 20초를 쓴다. 단순 상한 합 검사를 실제 공유 신호의 중단·Judge 시간 보존·상위 취소 전파 시험으로 교체했다. 전체 실행 기한을 넘기는 우회는 하지 않는다. 진행 중 Case 상세가 실패 문구를 보여 주고 자동 갱신하지 않던 표시도 수정했다.

네 번째 PDF 실행은 83.928초에 선입금·원격제어 비교와 CoVe·Red Team·Judge를 종결했지만 상품 Agent는 부분 실패였다. Provider 원장은 상품 판단 두 호출을 TIMEOUT/미확정 예약으로 보존했다. 개인 승인 안내를 '무조건 승인'으로 해석한 문구도 채택하지 않는다.

다음 후보는 Provider용 중첩 상태 union을 평탄화하고, 알려진 ref의 출력 제한은 유지한다. 서버는 확정 상태에 쓰인 **모든** 인용의 직접성·유효성·참고 여부를 검사한다. 하나의 유효한 ref 옆에 부적격 ref를 섞어도 확정하지 않는다. 개인 승인 심사 자료가 없는 확정은 정보 부족으로 낮추며, 독립 검토로 보류된 초기 단정문을 확정된 요약처럼 표시하지 않는다. 실패한 묶음이 있어도 나머지 호출의 정산을 기다린다. 기존 금액·시간 Gate 합격선을 변경하는 작업이 아니다.

다섯 번째 PDF는 45.694초에 SQL 23514로 실패했다. 네 Domain Agent는 모두 성공했지만, 법령 조회 두 건 중 두 번째 Evidence를 저장하지 못했다. 공식 법령 011359의 2026-09-08 시행 조문은 전날 UTC 기준으로 인용 불가 Snapshot이 만들어져 있었다. 오늘 실제 본문을 다시 읽고 인용 가능으로 판단해도 기존 불변 Snapshot이 반환돼 DB 방어가 차단했다. 원본 오류는 `pdf-fifth-failure.json`에 보존한다.

국내 법령 시행일을 한국 날짜로 판단하고, Snapshot 버전에 시행 전·후 조회 자격을 함께 고정한다. 공식 시행 버전은 `effective_from`과 locator의 `official_source_version`에 그대로 남는다. 이전 Snapshot과 Passport는 변경하지 않으며 본문 Hash·출처 지문도 그대로라 독립 출처 수가 늘지 않는다. 격리 DB 시험 43은 과거 인용 불가 행 재사용을 재현하고, 새 시행 후 Snapshot·반복 조회·과거 불변성을 확인한다.

여섯 번째 PDF는 법령 저장을 통과했으나 Judge 한 묶음의 20초 TIMEOUT으로 전체 판단을 버려 82.307초에 전부 보류됐다. 다른 Judge 묶음은 5.610초에 정상 정산됐다. `pdf-sixth-failure.json`에 실패를 보존한다. 최종 후보는 Judge 묶음별 실패를 격리해 성공 응답을 유지하며 실패 Claim은 UNKNOWN, Judge/Run은 부분 상태로 남긴다. 미확정 호출의 예약은 해제하지 않는다.

Provider용 형식은 근거 수와 무관하게 고정한다. 제공한 ref의 정확한 목록 검사는 모델 응답 복원 시 전수 수행하고, 인용 자격·독립 검토는 그 뒤 그대로 적용한다. 형식만 맞는 미제공 ref도 저장·확정할 수 없다. 새 Schema의 준비 지연은 Provider 문서가 설명하지만, 이번 TIMEOUT의 내부 지연 원인을 직접 측정한 것으로 표현하지 않는다. 시간·금액 상한과 정식 Gate 합격식은 유지한다.

### 원장 TIMEOUT 해석 정정

일곱 번째 실행은 76.102초에 Domain·CoVe·Red Team이 모두 성공했고 Judge 한 묶음은 실패했다. 기존 미확정 예약 함수가 **모든 미확정 응답을 TIMEOUT으로 기록**하는 점을 확인했다. 앞선 원장 값만으로 실제 시간 초과 또는 grammar 지연을 확정한 해석은 철회한다. 원본 응답이 없어 과거 미확정 예약은 임의 정산·해제하지 않는다.

SDK의 `messages.parse`는 로컬 Zod 검증을 끝내야 사용량을 반환한다. 형식 실패가 실제 수신 사용량을 가리고 미확정 예약으로 남을 수 있어, 동일한 구조화 출력 요청을 `messages.create`로 수신하고 형식 검사·실제 사용량 정산 뒤 안전한 오류 코드로 종결한다. 모델 본문과 오류에 포함될 수 있는 값은 기록하지 않는다. Judge 묶음 실패가 Domain 성공 때문에 Run에서 누락되지 않도록 부분 상태 전파도 보완했다. 실제 실패와 `partial:false` 응답은 `pdf-seventh-failure.json`에 보존한다.

### 행동 경고와 사실 판정의 분리

정상 예방 Text의 첫 Live 실행은 61.698초에 모든 단계가 성공했고, 선입금·원격제어를 거절하라는 두 항목은 VERIFIED, 개인 승인·특정 공식 앱의 개별 사실은 정보 부족으로 남았다. 위험 요구 오탐은 없었다. `negative-first-success.json`은 이 재현 표본의 결과이며 정식 판정 품질 채택이 아니다.

요구사항 2.2와 RES-004는 고위험 행동 요구를 사실 판정 보류보다 우선하도록 정하지만, 기존 Matrix에는 그 규칙 코드가 연결되지 않았다. Migration 0057의 v11·result-matrix-v2는 검토 기한 내 실제 조회한 공식 예방 지침과 명시적인 선입금·원격제어 앱 설치 요구가 함께 있을 때 행동 경고를 우선한다. Claim의 UNKNOWN/WITHHELD 등 상태와 Agent 실패는 그대로 보존하고, 범죄·악성 앱·발신자 신원을 확정하지 않는다. 정상 공식 앱·거절·금지·부정문은 요구로 취급하지 않는다. 규칙 코드·해당 Claim·공식 근거 연결·행동 가이드는 Passport에 함께 남는다. 이전 Matrix·Passport·모델·비용·시간 상한은 변경하지 않는다.

Judge 수신 구조와 결과 채택 검사를 분리해, 한 항목의 문장 형식 오류나 충돌 근거 부족 때문에 같은 묶음의 다른 정상 결과까지 폐기하지 않는다. 잘못된 문장은 해당 Claim만 WITHHELD, 성립하지 않은 충돌은 해당 Claim만 UNKNOWN으로 내리고 Judge·Run 부분 실패를 유지한다. 기존 인용 자격·공식 근거·최소 충돌 근거 조건은 그대로 검사한다. 실제 Provider의 과거 오류 종류를 이 코드 검토만으로 소급 확정하지 않는다.

여덟 번째 PDF는 71.755초에 행동 경고와 Passport를 저장했다. 선입금·원격제어 요구는 공식 지침과의 불일치로 판단했고, 종합 결과는 MATERIAL_RISK_FOUND, 거래 위험 축은 HIGH_RISK_ACTION이다. 개인 승인·금리·한도는 구분된 한계를 남겼다. Regulation의 항목 Coverage 실패와 Red Team 인용 일부 실패는 PARTIAL로 유지했다. 일반 예방 안내를 신청 기한의 직접 반증으로 쓴 문구도 발견해 결과를 전체 품질 성공으로 채택하지 않는다.

개별 신청 기한을 일반 예방 지침만으로 확정하는 인용은 Domain·Judge·독립 검토 모두에서 차단한다. 인용 자격 때문에 낮춘 상태에는 이전 단정 문구도 남기지 않는다. `pdf-eighth-partial.json`에 원본을 보존하고 다음 시험에 정상 예방 Text를 다시 포함한다.

## 최종 후보 재현과 검증 범위

코드 `69415ae7`의 같은 PDF는 검증 접수부터 82.861초에 Passport를 저장했다. 업로드 슬롯 발급·파일 분석 시간은 별도로 기록했다. 네 Domain·CoVe·Judge는 성공했고 Red Team의 인용 일부 실패는 PARTIAL로 남았다. 선입금·원격제어 요구에는 공식 근거와 중단 행동을 표시하며 종합 결과는 MATERIAL_RISK_FOUND, 거래 위험 축은 HIGH_RISK_ACTION이다. 신청 기한은 공식 자료 부족, 개인 승인은 심사 자료 부족, 종료 상품의 금리·한도는 현재 조건 확인 불가로 구분했다. 근거 없는 확정으로 바꾸지 않았다.
