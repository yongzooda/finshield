# 회원 권유 검증의 근거 사용 범위 수정

요구사항 CLM-001·AI-009·AI-010·EV-004·EV-007·EV-009·RES-004의 결함 수정이다. 사용자 제공 합성 PDF의 SHA는 `3b4edb0a7075f273ddfa1c426bb818bd4df2ae1c48011f8e191d17830cc53a1a`다. 이미 결과를 본 재현 표본이므로 정식 Claim 품질 평가셋으로 채택하지 않는다.

## Live 재실행 전 확인 기준

- 현재 가입 가능하다는 햇살론15 권유는 공식 보증 종료 고지와 비교해야 한다. 종료 전 조건을 현재 판매 조건으로 승격하지 않는다.
- 금리와 한도는 별도 Claim으로 추출하고 원문의 단위·상품 문맥을 보존한다.
- 사용자 확정 문구의 요구 조건이 공식 안내와 맞는지 검증한다. 실제 대화의 발생이나 상대의 범죄 사실을 입증하는 문제로 바꾸지 않는다.
- 선입금·원격제어 요청의 위험과 필요한 행동을 구체적으로 설명한다. 개인 승인 여부와 실제 발신자 신원은 자료가 없으면 보류한다.
- CoVe도 소비자 안내를 독립 조회할 수 있어야 한다. 초기 Agent 결과·검색을 재사용하지 않는다.
- 유사 사건·범죄 사실은 일반 안내만으로 확정하지 않는다. 종료 고지는 현재 가입 가능성을 뒷받침하는 인용에 사용할 수 없다.
- 부정문(선입금하지 말라, 원격제어 앱 설치를 거절하라)과 정상 공식 앱 신청을 위험 요구로 뒤집지 않는다. 실패·만료·본문 변경은 성공으로 숨기지 않는다.
- 같은 PDF의 업로드·선택·검증·저장·재조회·삭제를 실제로 확인한다. 전체 Release 또는 B-CLAIM-01 성공으로 표시하지 않는다.

## 출처 해석

현재 상품 페이지의 종료 안내는 '종료 사실'에 대한 직접 근거다. 해당 페이지의 종료 전 금리·한도는 현재 가입 가능성을 지지하지 않는 맥락 자료로 유지한다.

서민금융진흥원 공지 24020의 2021-05-27 예방 지침은 작성일을 보존한다. 일반 예방 지침의 공식 게시 내용과 현재 권유의 발생·사기 확정은 다른 명제다. 검토한 본문 Hash와 검토 기한을 명시하고, 기한 안에 같은 공식 본문을 다시 가져온 경우에만 안내 내용과 요구 조건의 비교에 사용한다. 본문 변경·검토 기한 만료 시 기존 참고 자료 상태로 돌아간다. 최신 사건 경보 또는 현재 거래의 위법 증거로 표현하지 않는다.
