# 공식 예방 공지 검토 기한

요구사항: `EV-007`, `EV-009`, `RES-004`. 관련 코드: `src/lib/finshield/tools/warning-review.ts`.

## 무엇에 쓰이나

서민금융진흥원 공지 24020(2021-05-27, 서민금융 사칭 및 불법사금융 피해 주의)의 네 문단을 공식 예방 지침으로 쓴다.
진흥원은 문자메시지나 전화로 금융상품 광고를 하지 않는다는 문단, 정상 금융기관은 대출 명목의 금전을 요구하지 않는다는 문단,
신용도에 관계없이 누구나 가능한 대출은 없다는 문단, 출처가 불분명한 앱·URL을 누르지 말라는 문단이다.

- 선입금·원격제어 앱 설치 요구의 고위험 행동 경고(`HIGH_RISK_ADVANCE_PAYMENT`·`HIGH_RISK_REMOTE_CONTROL`)는 이 공지가 비교 근거일 때만 켜진다.
- 회원 실행과 공개 Demo 의 예방 안내 조회가 이 공지를 실시간으로 읽는다.
- 일반 예방 지침이므로 현재 거래의 사기·위법 증명이나 개별 신청 기한의 반증으로 쓰지 않는다. 인용 검사가 막는다.

## 사용 조건

매 조회마다 공지를 다시 받아 본문 구간의 SHA-256 을 계산한다.
검토한 Hash 와 같고 검토 기한 안이면 비교 근거(`DIRECT`·인용 가능)가 된다.
본문이 바뀌거나 기한이 지나면 오류 없이 참고 자료(`CONTEXT_ONLY`)로 돌아간다.
그러면 고위험 행동 경고가 조용히 사라지므로 기한 관리가 필요하다.

## 재검토 절차

1. 공지를 다시 받아 `warning-section.mjs` 경계의 본문 Hash 가 `WARNING_REVIEW.contentHash` 와 같은지 확인한다.
2. 같으면 선택 문단 네 개가 위 설명과 같은 뜻인지 읽고 확인한다. Hash 가 같으면 글자도 같다.
3. `reviewedAt` 을 확인 시각으로, `reviewDueAt` 을 그 30일 뒤로 바꾼다.
4. `evidence/development/warning-review/` 에 확인 시각·HTTP 상태·Hash 를 남긴다. 본문 원문은 저장하지 않는다.
5. Hash 가 다르면 기한을 늘리지 않는다. 바뀐 본문을 새로 검토하고 문단 선택 규칙과 Hash 를 함께 바꾼다.

`source-refresh.yml` 의 `warning-review` job 이 6시간마다 본문 Hash 와 기한을 본다.
기한 72시간 전부터, 또는 본문이 바뀌면 실패해 관리자에게 알린다.

## 기한을 30일로 둔 까닭

처음 검토 기한은 7일(2026-09-08 → 09-15)이었다. 공지는 2021년 게시물이고 매 조회마다 본문 Hash 를 다시 확인하므로
본문 변경은 기한과 관계없이 즉시 걸린다. 기한은 지침이 여전히 적절한지 사람이 다시 볼 주기다.
7일마다 갱신을 놓치면 심사 기간 중 경고 기능이 조용히 꺼지므로 30일로 두고, 만료 전 알림을 예약 실행에 붙였다.
