## squash 줄바꿈으로 인한 재발 방지

GitHub은 PR 본문을 squash 커밋 메시지로 옮길 때 72열 기준 단어 단위로 다시 줄바꿈한다. 식별자와 수치가 길게 이어진 문장은 한국어가 없는 조각으로 잘릴 수 있고, 그러면 병합 뒤 main 검사와 일일 예약 검사만 실패했다. `219c7b6`이 이 경로로 실패했다.

PR 검사가 이제 본문을 squash 시점 형태로 줄바꿈한 뒤에도 각 행에 한국어가 남는지 함께 확인한다. 72열 단어 단위 greedy 줄바꿈이 실제 squash 본문을 재현한다는 사실은 병합된 `219c7b6`, `2ec62ab`, `9e6df85`로 확인했다. 긴 식별자 나열은 문장을 짧게 끊어 각 행에 한국어 설명을 남긴다.
