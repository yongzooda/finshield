# 가입 후 문서 비용 예약 거부

PC-008·N-OPS-003의 보호 Preview 계약 PDF 시험에서 TUS·격리 파서·마스킹까지 진행한 뒤 비용 예약이 42501로 거부됐다. 원격 0043의 해시 6종은 격리 기준과 일치했다. 0034의 비용 함수가 거래 전 Case lifecycle만 허용해 완료 Case의 AFTERCARE 입력을 거부한 것이다. Provider 호출 전 실패여서 사용량 증가·미확정 예약은 0이었다. 실패 Case는 API로 삭제하고 후속 조회 404를 확인했다.

Migration 0044는 소유자·활성 마스킹 입력·TTL·삭제 경계를 유지하면서 가입 등록과 Passport가 있는 AFTERCARE Image/PDF의 비용 예약을 허용한다. 거래 전 입력의 상태 제한은 유지한다. 계정 탈퇴와 같은 소유자 잠금을 사용하며 금액·Provider·정산·미확정 예약 규칙은 바꾸지 않는다.

격리 SQL은 기존 함수에서 같은 거부를 재현한 뒤 개별/합산 8범위 예약·정산, 상한 초과·타인·확인 완료 문서의 재예약 거부를 검사한다. 최초 수정 시험은 과거 Fixture의 미확정 비용 때문에 거부됐으며, 시험 트랜잭션에서만 Fixture 원장을 격리했다. 운영 원장에는 쓰지 않는다. 실패 원본은 보존한다.

기능 Draft에서는 최초 파일 소유권 거부와 처리 도중 DB 거부를 구분했다. 최초 거부·중복 소비는 입력을 중단하지 않으며, 마스킹 이후 DB 거부는 실패 종결과 원본 정리를 실행한다. 원격 0044 적용과 수정 후 실제 파일 재검증은 후속이다. 이 변경은 정식 Gate 채택이 아니다.
