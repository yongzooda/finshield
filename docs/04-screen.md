</tr>

<td>필수 구성</td>
<td>① 안내(통화가 녹음된다는 사실 · 시험이 아니라 기록이라는 성격) → ② 질문을 **한 번에 하나씩**(A11Y-4), 선택지 3개 이상(「기억이 안 나요」 계열 도피로 상시 — A11Y 「모름 상시 제공」의 연습판) → ③ 답을 고르면 **그 답이 무엇으로 기록되는지 해설**이 열리고 다음으로 — 해설을 건너뛰는 경로가 없다 → ④ 마무리: 답변 recap + 핵심 정리(사실대로 · 녹음 열람 요구 가능 · 교육용 고지)</td>
</tr>

<td>**모델·DB·외부 조회 전무** — 시나리오는 배포 번들의 코드 상수(`lib/happycall.ts`, S-12·브리핑과 같은 규약). 질문마다 근거(why) 병기 — 출처 없는 질문을 만들지 않는다. 분기 무결성(깨진 참조·도달 불가·해설 없는 선택지)은 테스트로 고정. 진행·답변은 **클라이언트 상태에만** 있고 서버 전송·저장이 없다(P-3) — 새로고침하면 처음부터이며 연습이므로 그것이 맞다</td>
