# 권한 요구사항
프리케이스(PreCase) — 2026 금융 AI Challenge 1차 심사 제출본
<callout icon="🎯" color="blue_bg">
	**이 문서의 역할** — 누가 무엇에 접근할 수 있는지 확정한다. 프리케이스는 **로그인·계정·역할이 없는 서비스**(SR-X06)이므로 이 문서의 핵심은 사용자 역할 구분이 아니라 ① 익명 접근의 경계, ② **에이전트 계층 간 내부 권한**, ③ 데이터 등급별 접근 통제다.
	사용자 권한이 얇은 대신 **시스템 내부 권한이 이 서비스의 안전 설계 그 자체**다 — 판단 계층의 원문 미접근(SR-402)이 편향 차단과 인젝션 방어를 동시에 담당한다.
</callout>

**실행 로그 규칙** — 각 계층은 자기 단계 기록만 **추가(append)** 가능하며, 어느 계층도 기록을 수정·삭제할 수 없다.
**P-401** — 위 매트릭스의 ❌는 프롬프트 지시가 아니라 **호출 구조에서 강제**한다. 판단 계층 호출 페이로드에 원문 필드 자체가 존재하지 않아야 한다.
**P-402** — ③ 판단이 추가 정보를 원하면 직접 조회가 아니라 **되돌림(F-308) 경로**로만 요청할 수 있다.

**P-501** — 런타임 DB 자격증명은 **정적 자산 SELECT + 신고 INSERT + 카운터 UPDATE**만 허용한다. 정적 자산에 대한 쓰기 권한을 런타임에 부여하지 않는다 — 인젝션이 성공해도 코퍼스를 오염시킬 수 없어야 한다 (Q-4·F-606과 정합).
**P-502** — 배치 자격증명은 런타임과 분리하고 배포 환경에 저장하지 않는다.
